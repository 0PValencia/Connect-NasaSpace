# NASA Space Apps Challenge 2025 - Frontend

Este proyecto son las trivias de la aplicación **Connect** para el NASA Space Apps Challenge 2025.

## Requisitos

- Node.js 18+
- [pnpm](https://pnpm.io/) instalado globalmente

## Instalación

1. Clona el repositorio:
   ```bash
   git clone : https://github.com/0PValencia/Connect-NasaSpace.git
   cd NASA/Frontend
   ```

2. Instala las dependencias:
   ```bash
   pnpm install
   ```

## Uso en desarrollo

```bash
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la app.

## Estructura

- `app/` - Páginas y layout principal.
- `components/` - Componentes reutilizables.
- `public/` - Imágenes y archivos estáticos (incluye el logo).
- `lib/` - Lógica y datos compartidos.
- `hooks/`
- `lib/`
- `styles/`
- `types/`

## Scripts útiles

- `dev`: Ejecuta el servidor de desarrollo.
- `build`: Compila la app para producción.
- `start`: Inicia la app en modo producción.

## Deploy

Puedes desplegar fácilmente en [Vercel](https://vercel.com/) o cualquier plataforma compatible con Next.js.
